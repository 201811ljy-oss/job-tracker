# 🏢 央国企求职追踪

> 专为 2027 届应届生打造的轻量级央国企求职管理工具。基于 PWA 技术，支持离线使用、跨设备同步，让求职进度一目了然。

---

## 📌 项目简介

本项目是一个面向**物流管理 / 供应链 / 采购**等方向应届生的**央国企求职追踪系统**。预置 40+ 家目标企业（基建工程局、央企地方分支、河北省属国企、其他央企子公司），支持自定义添加企业、状态追踪、多设备云端同步。

**核心定位**：放弃海投焦虑，专注央国企赛道，用数据驱动求职决策。

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📋 **企业库管理** | 预置 40+ 家央国企，分 4 档（基建工程局 / 央企分支 / 河北省属 / 其他央企），支持自定义添加 |
| 🔄 **状态追踪** | 8 种投递状态：未投递 → 已投递 → 测评中 → 笔试 → 面试 → 已录用 / 已拒绝 / 放弃 |
| ☁️ **云端同步** | 基于 GitHub `data.json` 实现跨设备数据同步，手机/电脑无缝切换 |
| 📊 **数据看板** | 顶部实时统计：目标企业数、已投递/进行中、面试中、已录用、投递率 |
| 🔍 **智能筛选** | 按企业类型筛选（全部 / 基建工程局 / 央企分支 / 河北省属 / 其他央企 / 自定义） |
| 🔎 **搜索** | 支持企业名称、岗位关键词搜索 |
| 📱 **PWA 支持** | 可安装到手机桌面，离线可用，Service Worker 缓存加速 |
| 📤 **数据导出** | 支持导出 CSV，方便备份或导入 Excel 分析 |
| 🔔 **Token 失效检测** | 自动检测 GitHub Token 过期，明确提示重新配置 |

## 🚀 快速开始

### 在线使用（推荐）

直接访问：👉 **[https://201811ljy-oss.github.io/job-tracker/](https://201811ljy-oss.github.io/job-tracker/)**

### 安装到手机桌面

- **Android Chrome**：打开页面 → 点击菜单 → "添加到主屏幕"
- **iOS Safari**：打开页面 → 点击分享按钮 → "添加到主屏幕"

### 配置云端同步

1. 打开页面，点击右上角 **⚙️ 齿轮**
2. 生成 GitHub Token（[https://github.com/settings/tokens](https://github.com/settings/tokens)）
   - 选择 **Generate new token (classic)**
   - 勾选 **`repo`** 权限
   - **Expiration 建议选 No expiration**
3. 复制 `ghp_...` 开头的 Token，粘贴到设置面板
4. 点击 **保存并同步**

> 💡 配置完成后，任何设备上的数据变动都会自动同步到云端，其他设备刷新即可获取最新数据。

## 🏗️ 技术架构

```
┌─────────────────────────────────────────┐
│           PWA 前端 (GitHub Pages)         │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐ │
│  │ index.html│  │  sw.js  │  │manifest │ │
│  │ (UI+逻辑) │  │(离线缓存)│  │(PWA配置)│ │
│  └─────────┘  └─────────┘  └─────────┘ │
│              localStorage (本地数据)       │
└─────────────────────────────────────────┘
                    │
                    ▼  GitHub API (PUT/GET)
┌─────────────────────────────────────────┐
│     GitHub Repository: data.json         │
│     (云端数据持久化 + 跨设备同步)          │
└─────────────────────────────────────────┘
```

- **前端**：原生 HTML + CSS + JavaScript，零框架依赖
- **存储**：localStorage（本地）+ GitHub API（云端）
- **PWA**：Service Worker 离线缓存，manifest 桌面安装
- **部署**：GitHub Pages 自动部署

## 📝 使用技巧

1. **批量操作**：先筛选"未投递"，逐一点击状态改为"已投递"，效率最高
2. **备注活用**：面试后记录面试官问题、公司氛围，方便后续复盘
3. **自定义企业**：遇到清单外的目标企业，点右下角 ➕ 快速添加
4. **定期备份**：虽然云端同步，但建议每月导出一次 CSV 备份
5. **投递率监控**：保持投递率 > 30%，低于 20% 说明进度偏慢需加速

## 🔧 常见问题

**Q: 点击同步提示"推送失败"？**
> GitHub Token 已过期。打开 ⚙️ 设置，重新生成 Token（建议选 No expiration）。

**Q: 手机添加的数据电脑看不到？**
> 两端都需要配置同一个 Token。确认手机端和电脑端设置的是同一个 `ghp_...` Token。

**Q: 页面加载后还是旧版本？**
> Service Worker 缓存导致。完全关闭浏览器再重新打开，或清除站点数据后刷新。

**Q: 可以多人共用吗？**
> 可以。多人配置同一个 Token 即可共享同一份数据，适合求职小组协作。
